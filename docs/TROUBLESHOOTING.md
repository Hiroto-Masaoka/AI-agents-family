# TROUBLESHOOTING — トラブルシューティング

発生した問題と解決方法を記録します。同じ問題に再び遭遇したときに検索できるよう、**症状(エラーメッセージ)をそのまま** 書いてください。

- ID:`T-xx`。追記のみ。
- 未解決の問題は OPEN_ISSUES に書き、解決したらここへ記録する。

## テンプレート

```markdown
### T-xx: <症状の短い説明>
- 日付 / 関連: YYYY-MM-DD / LOG-..., #Issue
- 症状: <エラーメッセージ・現象>
- 環境: <OS、ツール、モデル、バージョン>
- 原因: <確認できた原因(推定の場合は Unverified と明記)>
- 解決方法: <手順>
- 再発防止: <あれば>
```
