# PROJECT_OVERVIEW — プロジェクト概要

最終更新: 2026-11-16(ADR-0008 で当面の優先順位を変更)/ 情報源: ユーザー提供のミッション文書(`docs/PROMPTS/2026-11-16_repository-setup-mission.md`)および 2026-11-13 の claude.ai 上の議論

## 1. 背景

開発者(電波天文学者)は、研究を効率化して本来の関心事に集中し、ブレークスルーにつなげるために、複数の AI モデルが役割分担して協働する「**AI-Agent family(AI エージェントの家族)**」を構築したいと考えている。(Decided)

当面は、**日々の研究・業務を支援する実用的な汎用 AI-Agent** を作りながら、エージェント開発の実践経験を積む。(Decided、[ADR-0008](DECISIONS/ADR-0008-general-purpose-agents-first.md))

将来は、そこで作った仕組みを **自前の電波望遠鏡の観測運用** に応用する。(Planned。当初は最初の目標としていたが、2026-11-16 に延期を決定)

開発者は AI-Agent 開発の経験がまだ浅いため、初心者でも後から経緯を追えるドキュメントと、小さく試して学べる開発の進め方を重視する。(Decided)

## 2. 最終目標

| 目標 | 内容 | ラベル |
|------|------|--------|
| **当面の目標** | 日常業務・研究を支援する汎用 AI-Agent:コーディング・ソフトウェア開発 / 研究・文献調査 / データ分析・ドキュメント作成 / 定型作業の自動化 / 研究資金の公募調査・申請支援 / 正当な AI 活用の収益機会の調査 | Decided(ADR-0008) |
| 学習目標 | エージェントの構成、ツール連携、メモリ、ワークフロー、マルチエージェント協調、評価を実際に作って身につける | Decided(ADR-0008) |
| 将来の目標 | 日常的な電波望遠鏡の観測運用の自動化(旧・最初の目標、ADR-0003 → ADR-0008 で延期) | Planned |
| 将来の目標 | 観測システムの長期的な自律運用 | Planned(構想) |
| 将来の目標 | FRB(高速電波バースト)などの突発天体に対する自動追観測 | Planned(構想) |
| 発展 | X 線衛星など他の観測システムにも使える汎用 AI-Agent | Planned(構想) |
| 発展 | 研究以外(Web 制作、ゲーム開発、資産管理など)にも使える「エージェント家族の作り方」の確立 | Proposed |

> 「構想」は、実現方法がまだ決まっていないものを指します。実装済みの機能は現時点で **ありません**。

## 3. 開発方針

| 方針 | ラベル | 記録 |
|------|--------|------|
| 小さく実装・試験・評価を繰り返し、作りながら学ぶ | Decided | [ADR-0002](DECISIONS/ADR-0002-incremental-development.md) |
| GitHub リポジトリを開発の中心的なナレッジベースにする | Decided | [ADR-0001](DECISIONS/ADR-0001-github-as-knowledge-base.md) |
| LLM の実行環境は商用 API と自前計算機を併用する | Decided(具体的な製品・構成は未定) | [ADR-0004](DECISIONS/ADR-0004-hybrid-llm-environment.md) |
| 情報を 5 段階の信頼性ラベルで分類し、推測を事実として記録しない | Decided | [ADR-0005](DECISIONS/ADR-0005-reliability-labels.md) |
| 特定の実装に依存せず、設計思想・技術選定・ノウハウを再利用できる形で残す | Decided | 本ドキュメント群全体 |
| 観測装置を動かす操作は、人間の承認を経てから段階的に自動化する | Proposed | [ADR-0006](DECISIONS/ADR-0006-human-in-the-loop-safety.md) |
| まず単一エージェントで始め、必要が証明されたときだけエージェントを増やす | Proposed | [ADR-0007](DECISIONS/ADR-0007-start-with-single-agent.md) |

## 4. 対象システム

### 4.0 当面の対象(Phase 1〜4)

開発者自身の日常業務・研究:このリポジトリを含むコード・文書、論文(arXiv など)、研究データ、定型作業、研究資金の公募情報。Phase 1 ではこれらを **読み取るだけ**(ADR-0009)。

### 4.2 将来の対象(構想)

- X 線衛星などの観測システム(Planned)
- 共通化の考え方:観測装置ごとに異なる部分(装置インターフェース)と、共通にできる部分(計画・監視・記録・判断の仕組み)を分けて設計する。(Proposed、[ARCHITECTURE](ARCHITECTURE.md) 参照)

## 5. このプロジェクトで「やらないこと」(現時点)

- Phase 1 では、エージェントにファイル変更・システム変更・外部への書き込みをさせない。(Decided、ADR-0009)
- 望遠鏡固有の開発は Phase 5 まで行わない。(Decided、ADR-0008)
- 人間の確認なしに観測装置を操作する仕組みは、十分な試験と段階的な権限拡大を経るまで作らない。(Proposed)
