# ADR-0001: GitHub リポジトリを開発の中心的なナレッジベースにする

- **Status:** Decided
- **日付:** 2026-11-16
- **決定者:** 開発者(ミッション文書で指示)
- **関連:** LOG-20261116-02

## 背景
AI(Claude、ChatGPT など)との対話で議論・設計が進むが、会話の内容は別のセッションや別の AI から参照できない。AI-Agent 開発が初めてのため、後から経緯をたどれる記録が必要。

## 選択肢
1. **GitHub リポジトリ(Markdown)に集約** ← 採用
2. 各 AI サービスのプロジェクト機能・メモリに頼る
3. Notion などの外部ノートツール

## 決定理由
- どの AI からも読める(ファイルとして渡せる、Claude Code などは直接読める)。
- コードと文書が同じ場所で、同じ履歴(Git)で管理できる。
- 特定のサービスに依存しない。

## トレードオフ
- 書き出す手間がかかる(→ テンプレートと AGENTS.md で AI に書かせて軽減)。
- 図や表の表現力は Notion 等より劣る(→ Mermaid で補う)。
