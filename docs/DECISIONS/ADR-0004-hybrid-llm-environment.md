# ADR-0004: LLM 実行環境は商用 API と自前計算機を併用する

- **Status:** Decided(併用するという方針のみ)。**どの API・どのローカルモデルを使うか、役割分担は未定(Proposed)**
- **日付:** 2026-11-16
- **決定者:** 開発者
- **関連:** TECH_STACK §2.1・§3.2、OPEN_ISSUES Q-04・Q-05

## 背景
観測運用では、高度な判断が必要な場面と、大量・定型・常時の処理が混在する。また通信断や、外部に出せないデータへの対応も考える必要がある。

## 選択肢
1. 商用 API のみ
2. ローカル LLM のみ
3. **併用** ← 採用

| | 商用 API | ローカル LLM |
|---|---|---|
| 性能 | 高い | 計算機に依存(一般に劣る) |
| コスト | 従量課金 | 初期投資・電気代 |
| データ | 外部に送られる | 外に出ない |
| 通信断 | 使えない | 使える |

## 決定理由
両者の長所を使い分けるため。

## トレードオフ
- 2 種類の環境を保守する手間。
- モデルごとに挙動が異なるため、試験も両方で必要。

## 未決定事項
役割分担の案は TECH_STACK §3.2(Proposed)。Phase 1 以降の実験で決める。
