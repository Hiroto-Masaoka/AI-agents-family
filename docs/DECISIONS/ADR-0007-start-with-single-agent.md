# ADR-0007: 単一エージェントから始め、必要が示されてから分割する

- **Status:** Proposed(AI による提案。開発者の承認待ち)
- **日付:** 2026-11-16
- **関連:** BASICS §4、references/agent-family-playbook.md、LOG-20261113-01

## 背景
最終的には複数のエージェントが役割分担する「AI-Agent family」を目指している。しかし最初から多数のエージェントを作ると、調整が複雑になりコストも増える。

## 選択肢
1. **単一エージェントで始め、試験で具体的な問題(情報が多すぎる、並列化したい、独立検証が必要)が見えたら分割** ← 提案
2. 最初から役割ごとに複数のエージェントを作る

## 提案理由
- 公開情報では、エージェント数に対して調整コストが非線形に増えること、まず 1〜3 個から始めることが推奨されている(本プロジェクトでは未検証)。
- 初心者にとって、単一エージェントの方が挙動を理解・デバッグしやすい。

## トレードオフ
- 「家族」としての構成が見えるまで時間がかかる。

## 分割の判断基準(案)
最初に分割する候補は **検証役**(作業した本人に結果を採点させないため)。
