# ADR-0006: 観測装置の操作は人間の承認を前提に段階的に自動化する

- **Status:** Proposed(AI による提案。開発者の承認待ち)
- **日付:** 2026-11-16
- **関連:** ARCHITECTURE §4、ROADMAP Phase 4

## 背景
AI-Agent は誤った判断をすることがあり、観測装置の誤操作は装置の損傷や観測機会の損失につながりうる。

## 選択肢
1. **権限を段階的に広げる:読み取りのみ → 提案のみ → 人間承認後に実行 → 実績のある操作だけ自動** ← 提案
2. 最初から自動実行し、監視で対処する

## 提案理由
- LLM は「ツールを呼びたい」と出力するだけで、実行はプログラム側が行う。したがって承認の仕組みは確実に組み込める(BASICS §2)。
- 指示文(プロンプト)によるお願いではなく、プログラム側のガードレール(禁止操作・安全範囲・承認必須)で強制する。
- 公開事例でも、研究用エージェントは読み取り専用・人間参加型から始めることが推奨されている(references 参照、本プロジェクトでは未検証)。

## トレードオフ
- 完全自動化(特に突発天体への即時追観測)までに時間がかかる。即時性が必要な操作は、Phase 6 で個別に安全条件を定めて自動化を検討する。

## 未確認事項
装置側に安全インターロック(ハードウェア的な保護)があるか(OPEN_ISSUES Q-02)。
