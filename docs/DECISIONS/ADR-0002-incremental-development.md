# ADR-0002: 小さく実装・試験・評価を繰り返す段階的開発

- **Status:** Decided
- **日付:** 2026-11-16
- **決定者:** 開発者
- **関連:** ROADMAP、EXPERIMENTS/README.md

## 背景
AI-Agent 開発は初めてであり、最初から大きなシステムを設計しても、正しいかどうか判断できない。観測装置を扱うため、失敗の影響も大きい。

## 選択肢
1. **小さな機能を作り、試験し、評価して次に進む** ← 採用
2. 全体を先に設計してから一気に実装する

## 決定理由
- 各段階で学んだことを次の設計に反映できる。
- 失敗が小さく、原因が特定しやすい。
- 公開されている事例でも「小さく始めて測定しながら拡張する」ことが推奨されている(references 参照、本プロジェクトでは未検証)。

## トレードオフ
- 全体最適の設計にならない可能性がある(→ ARCHITECTURE で全体像を「提案」として持ち、段階ごとに見直す)。

## 実施方法
各フェーズに完了条件を設け(ROADMAP)、試験課題で評価し(EXPERIMENTS)、変更は一度に 1 つ。
