# ADR-0005: 情報を 5 段階の信頼性ラベルで分類する

- **Status:** Decided
- **日付:** 2026-11-16
- **決定者:** 開発者
- **関連:** README、AGENTS.md

## 背景
AI はもっともらしい推測を事実のように書くことがある(ハルシネーション)。また構想と実装済みの機能が混同されやすい。

## 決定
すべての情報に次のラベルを付ける:Confirmed(確認済み)/ Decided(決定済み)/ Proposed(提案・検討中)/ Planned(予定)/ Unverified(未検証)。不明な情報は「未確認」と書き、OPEN_ISSUES に登録する。

## 理由
- 読み手(人・AI)が情報の確かさを判断できる。
- 構想段階の内容を実装済みと誤解するのを防ぐ。
