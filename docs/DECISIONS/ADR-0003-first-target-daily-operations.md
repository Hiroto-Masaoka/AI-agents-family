# ADR-0003: 最初の目標を日常的な観測運用の自動化とする

- **Status:** Superseded by [ADR-0008](ADR-0008-general-purpose-agents-first.md)(2026-11-16。以下の本文は決定当時のまま)
- **日付:** 2026-11-16
- **決定者:** 開発者
- **関連:** PROJECT_OVERVIEW、ROADMAP

## 背景
将来的には長期自律運用や FRB などの自動追観測を目指すが、それらは高度で、判断ミスの影響も大きい。

## 選択肢
1. **日常的な観測運用の自動化から始める** ← 採用
2. FRB 検出・自動追観測から始める
3. データ処理の自動化だけに絞る

## 決定理由
- 日常運用は繰り返しが多く、効果が分かりやすい。
- 将来の高度な機能(異常検知、追観測)の土台(状態監視、ログ、制御インターフェース)になる。

## トレードオフ
- 研究上のインパクトが大きい FRB 追観測の実現は後回しになる。

## 補足(Proposed)
日常運用の中でも、リスクの低い「読み取り(状態監視)」と「データ処理」から始め、装置の「操作」は後に回す順序を ROADMAP で提案している(ADR-0006)。
