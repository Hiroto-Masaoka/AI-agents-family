# EXPERIMENTS — 実験・試験記録

1 つの実験・試験につき 1 ファイルで記録します。**失敗した実験も必ず残してください。**

- ファイル名:`EXP-YYYYMMDD-<短い英語名>.md`
- テンプレート:[../templates/EXPERIMENT.md](../templates/EXPERIMENT.md)
- 実施したら DEVELOPMENT_LOG にエントリを作り、相互にリンクする。

## 評価の基本(初心者向け)

1. **試験課題を先に決める**:実際の業務から 5〜20 個。答えが分かっている課題を必ず含める。
2. **ベースラインを取る**:最小構成(単一エージェント)での成功率・時間・コスト。
3. **一度に 1 つだけ変える**:プロンプト、ツール、モデル、構成のどれか 1 つ。
4. **全課題を再実行する**:改善した課題だけでなく、悪化した課題がないかを見る。
5. **良くなったときだけ変更を残す。**
