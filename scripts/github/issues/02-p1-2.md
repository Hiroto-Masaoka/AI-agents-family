## 目的と動機
文献調査を支援する。外部 API をツールとして使い、存在しない論文の捏造(ハルシネーション)を検証スクリプトで防ぐ方法を学ぶ。

## 必要な能力・ツール
`search_arxiv`・`get_arxiv_paper`(HTTP GET のみ)/ 任意で NASA ADS / 引用検証スクリプト(LLM 不使用)

## 受け入れ基準(Acceptance criteria)
- [ ] 3 テーマで上位 10 件の文献リストと要約を作成
- [ ] 架空の文献 0 件(全 ID が実在しタイトル一致)
- [ ] 各テーマ 10 件中 8 件以上が関連あり(開発者判定)
- [ ] 要約中の主張の 100% に論文 ID
- [ ] ツール呼び出し 20 回以内、時間・トークン数を記録
- [ ] 外部通信は GET のみ(トレースで確認)

## 共通ルール(Read-Only)
- エージェントに書き込み・削除・任意のシェル/コード実行・POST 系 API のツールを与えない([ADR-0009](https://github.com/Hiroto-Masaoka/AI-agents-family/blob/main/docs/DECISIONS/ADR-0009-phase1-read-only-policy.md))
- 読み取り範囲は許可リストでプログラム側から制限する。出力は標準出力
- 試験前後で対象ディレクトリの SHA-256 一覧が一致することを確認する
