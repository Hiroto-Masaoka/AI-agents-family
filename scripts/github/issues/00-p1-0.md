## 目的と動機
P1-1 以降を **2 つの実行方式で公平に比較** するため、共通部分と両方式の入口を先に用意する([ADR-0012](https://github.com/Hiroto-Masaoka/AI-agents-family/blob/main/docs/DECISIONS/ADR-0012-dual-track-comparison.md))。

- **Track A:** Claude Agent SDK(Python)を Claude Pro アカウントで使う(Pro の利用枠内)
- **Track B:** Messages API を API キーで直接呼び、エージェントループを自作する(従量課金)

## 作業内容
- [ ] Python 環境を作成(uv / conda / venv から選び ADR-0010 に追記)
- [ ] Track A:Agent SDK を導入し、Pro アカウントでログインして動作確認
- [ ] Track B:Claude Console で API キーを取得して `.env` に保存(コミットしない)、**月の予算上限を設定**(OPEN_ISSUES Q-12)
- [ ] 共通部分の雛形:ツール定義の形式、許可リスト、トレース形式(OPEN_ISSUES P-04)、評価ハーネスの入口
- [ ] Pro プランで使えるモデルの範囲を確認(OPEN_ISSUES Q-13)

## 受け入れ基準(Acceptance criteria)
- [ ] 両方式で「ツールを 1 回呼んで答える」最小の動作確認ができる(2/2)
- [ ] 両方式が同じトレース形式で記録される
- [ ] API キーがリポジトリに含まれない(`git grep` で 0 件)
- [ ] 予算上限の金額を DEVELOPMENT_LOG に記録(キーは書かない)
