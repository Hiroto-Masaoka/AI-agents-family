## 目的と動機
データ分析とコード理解を支援する。計算は決まった関数(ツール)に任せ、LLM は手順の組み立てと解釈だけを担う設計を学ぶ。

## 必要な能力・ツール
`describe_table`・`summary_stats`・`filter_count`・`group_aggregate`・`read_file` / 任意のコード実行ツールは与えない / 公開 CSV と既存コード

## 受け入れ基準(Acceptance criteria)
- [ ] 数値の質問 10 問中 9 問以上が独立に計算した正解値と一致(許容誤差を事前定義)
- [ ] 数値回答の 100% がツールの計算結果に基づく(トレースで確認)
- [ ] コード読解 5 問中 4 問以上が正しい(開発者判定)
- [ ] 試験前後の SHA-256 一覧が完全一致
- [ ] **Track A(Agent SDK・Pro 枠)と Track B(API 直接)の両方で実行し、比較表を EXP 記録に残す**([§2](https://github.com/Hiroto-Masaoka/AI-agents-family/blob/main/docs/EXPERIMENTS/PHASE1_TEST_PLAN.md#2-2-つの実行方式の比較track-a--track-b))

## 共通ルール(Read-Only)
- エージェントに書き込み・削除・任意のシェル/コード実行・POST 系 API のツールを与えない([ADR-0009](https://github.com/Hiroto-Masaoka/AI-agents-family/blob/main/docs/DECISIONS/ADR-0009-phase1-read-only-policy.md))
- 読み取り範囲は許可リストでプログラム側から制限する。出力は標準出力
- 試験前後で対象ディレクトリの SHA-256 一覧が一致することを確認する
