## 目的と動機
定型作業の自動化の第一歩。複数の情報源(git log、GitHub Issue、arXiv 新着、最近の更新ファイル)を読み取り、日次ダイジェストを作る。ツールを読み取り専用の MCP サーバーとして作り、複数の AI クライアントから再利用できることを確かめる。

## 必要な能力・ツール
自作の読み取り専用 MCP サーバー / MCP クライアント 2 種 / 手動実行(定期実行の設定は Phase 1 では行わない)

## 受け入れ基準(Acceptance criteria)
- [ ] 過去 5 日分の正解項目一覧に対し再現率 平均 90% 以上
- [ ] 適合率 平均 90% 以上
- [ ] 2 種類のクライアントで動作
- [ ] 公開ツールに書き込み・削除・POST 系が 0 個(ツール監査)
- [ ] 1 回あたりの時間・コストを記録

## 詳細(実装の概要・試験手順)

## 共通ルール(Read-Only)
- エージェントに書き込み・削除・任意のシェル/コード実行・POST 系 API のツールを与えない([ADR-0009](https://github.com/Hiroto-Masaoka/AI-agents-family/blob/main/docs/DECISIONS/ADR-0009-phase1-read-only-policy.md))
- 読み取り範囲は許可リストでプログラム側から制限する。出力は標準出力
- 試験前後で対象ディレクトリの SHA-256 一覧が一致することを確認する
